# Spacehub Barcelona — web

Web estática de Spacehub Coworking (Sarrià - Sant Gervasi), publicada en https://spacehub.barcelona con GitHub Pages.

- `index.html` (español, principal) y `en/index.html` (inglés) se generan con `python3 build.py`; edita los textos ahí.
- `styles.css` contiene todo el estilo.
- `sitemap.xml` y `robots.txt` para Google.
